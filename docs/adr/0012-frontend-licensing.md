# 0012. Лицензии фронтенд-зависимостей: PrimeVue 4 (MIT) вместо PrimeVue 5

## Статус
Принято (2026-09-26)

## Контекст

В `CLAUDE.md` в качестве UI-библиотеки выбран PrimeVue (таблицы с виртуальным скроллом, TreeTable). При сборке фазы 1 была установлена последняя версия, PrimeVue 5.0.1. На первом же скриншоте интерфейса появилась плашка **«Invalid PrimeUI License»**.

Разбор пакета показал:
- с версии 5 PrimeVue (а также `primeicons` 8 и `@primeuix/themes` 3) распространяется под коммерческой **PrimeUI License**: нужен лицензионный ключ, без него показывается баннер;
- бесплатная Community License доступна студентам и маленьким организациям, но требует ежегодного подтверждения права на неё;
- лицензия запрещает удалять механизм проверки ключа.

Система предназначена для внедрения в организации в изолированном контуре. Зависимость, которой нужен ежегодно продлеваемый ключ, — это эксплуатационный и юридический риск: например, после обновления стенд может начать показывать баннер.

## Варианты

1. **PrimeVue 5 + Community License.** Ключ бесплатный, пока проект дипломный, но при внедрении в организации, скорее всего, понадобится коммерческая лицензия.
2. **PrimeVue 4.5.x (MIT)** — последняя ветка под MIT. Набор компонентов, нужный проекту (TreeTable, DataTable с виртуальным скроллом, TreeSelect, Dialog, Toast), в ней уже есть.
3. **Другая библиотека** (Naive UI, Element Plus, Quasar — все MIT). Потребует переписать уже готовые экраны и отступить от стека, зафиксированного в `CLAUDE.md`.

## Решение

**Вариант 2.** Версии закреплены точно, без `^`: `primevue@4.5.5`, `@primeuix/themes@2.0.3`, `primeicons@7.0.0`. В `just lint` добавлена проверка `npm run check:licenses` (`frontend/scripts/check-licenses.mjs`): она падает, если у production-зависимости не пермиссивная лицензия (разрешены MIT, ISC, BSD, Apache-2.0, 0BSD).

## Последствия

- Обновлять PrimeVue можно только в пределах ветки 4.x. Переход на 5.x возможен только отдельным ADR с решением по лицензии.
- Если ветка 4.x перестанет получать исправления безопасности, это станет поводом пересмотреть решение (вариант 3). Для изолированного контура без доступа в интернет этот риск ниже обычного.
- Проверка лицензий защищает и от других пакетов, которые в будущем могут сменить лицензию.
