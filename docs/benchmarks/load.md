## Методика и допущения

- Темп оператора в №62 не задан. Основной профиль — действие в среднем раз в 10 с (просмотр таблицы, выбор человека, чтение карточки занимают время). Стрессовый профиль с паузой 3 с — втрое плотнее — показывает запас: `just load run --think 3 --name load-stress` → `docs/benchmarks/load-stress.md`.
- Генератор нагрузки работает на той же машине, что и стенд, и делит с ним процессор; стенд использует ресурсы Docker целиком, эталон — 8 CPU / 16 ГБ.
- Узкие места, найденные и исправленные этим прогоном, — в плане фазы 7 (`docs/plans/phase-7.md`, статус шага 7d) и ADR-0004.
